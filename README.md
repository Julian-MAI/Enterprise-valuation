# 企业估值工具

一个面向 A 股公司的估值脚本，自动完成：
- 公司信息与市场快照抓取
- 财报公告收集与解析（优先 CNINFO）
- 标准化财务数据构建（含 TTM / 回退估算）
- 多模型估值与方法推荐
- 估值结果与说明文件输出

主入口文件：main.py

## 功能概览

程序执行 4 个阶段：
1. 抓取公司原始数据
2. 标准化财务数据
3. 执行估值模型
4. 输出结果文件

内置估值方法：
- DCF 现金流折现
- 市盈率法（PE）
- 市销率法（PS）
- EV/EBITDA
- 资产基础法
- 可比公司法（由可用市场法结果中位数生成）

## 环境要求

- Python 3.10+
- 网络可访问以下数据源：
  - cninfo（巨潮资讯）
  - eastmoney（东方财富）

## 安装依赖

在企业估值目录执行：

```bash
pip install pyyaml akshare pdfplumber
```

说明：
- `pyyaml`：读取估值和行业配置
- `akshare`：部分公告数据获取
- `pdfplumber`：财报 PDF 解析

## 运行方式

### 方式 1：命令行直接指定股票

```bash
python main.py --stock 股票代码 --name 公司名称
```

### 方式 2：交互输入

```bash
python main.py
```

程序会提示输入：
- 股票代码（必填）
- 公司名称（可选，可回车跳过）

## 参数说明

- `--stock`：股票代码，例如 `000001`
- `--name`：公司名称（可选）

## 输出目录与文件

每次运行会在 `data/<股票代码>/` 下生成或更新文件。

典型输出包括：
- 财报公告.md
- reports_pdf/
- reports_md/
- 财报解析结果.csv
- 原始行情快照.json
- 标准化财务数据.csv
- 估值参数.csv
- `<股票代码>_估值结果.csv`
- `<股票代码>_公式说明.csv`
- `<股票代码>_敏感性分析.csv`
- `<股票代码>_估值报告.txt`

## 配置文件

配置目录：`config/`

- `valuation_params.yaml`
  - 无风险利率、市场风险溢价、Beta、WACC、永续增长率
  - 行业 PE / PS / EV-EBITDA 倍数
- `industry_config.yaml`
  - 行业关键词映射
  - 各行业推荐估值方法优先级

如需调整估值风格（保守/激进），优先修改以上两个配置文件。

## 数据口径说明

- 单位：多数财务字段已统一到“万元”口径；估值输出主要以“亿元”展示。
- 报告优先级：优先使用财报解析结果；若关键字段缺失，可能回退到市场快照估算。
- TTM：当最新披露不是年报时，会尝试用“最近年报 + 最新期 - 上年同期”合成 TTM 口径。

## 常见问题

1. 运行报错 `ModuleNotFoundError`
- 重新安装依赖：`pip install pyyaml akshare pdfplumber`
- 确认当前终端路径在企业估值目录。

2. 估值结果为空或不可用
- 可能缺少关键财务字段（如现金流、净利润、收入）。
- 查看 `<股票代码>_估值报告.txt` 的“风险与告警”章节定位原因。

3. 抓不到公告或行情
- 检查网络连通性。
- 同一只股票稍后重试（接口偶发波动）。
